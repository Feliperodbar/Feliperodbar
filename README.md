# 🚀 Projetos em Destaque

## 🧪 AutoCase

### Gerador Inteligente de Casos de Teste

O **AutoCase** é uma aplicação em desenvolvimento voltada para profissionais e times de QA, criada para transformar requisitos e especificações em **casos de teste estruturados com apoio de Inteligência Artificial**.

A proposta é reduzir o trabalho repetitivo durante a elaboração dos testes e permitir que o profissional de QA dedique mais tempo à análise de riscos, cobertura e qualidade do produto.

### Principais recursos

- 🤖 Geração de casos de teste com IA
- 📋 Análise de requisitos
- ✅ Cenários positivos
- ❌ Cenários negativos
- ⚠️ Casos limite e exceções
- 🔄 Testes de integração e regressão
- 🎯 Classificação por prioridade e risco
- 🔗 Matriz de rastreabilidade
- 📊 Indicadores de cobertura
- 🤖 Identificação de candidatos à automação
- 📤 Exportação em diferentes formatos
- 🧠 Integração com diferentes provedores de LLM

### Visão do projeto

```text
REQUISITO
    ↓
ANÁLISE COM IA
    ↓
CENÁRIOS DE TESTE
    ↓
CLASSIFICAÇÃO DE RISCO
    ↓
RASTREABILIDADE
    ↓
COBERTURA
```

🔗 [Acessar repositório do AutoCase](https://github.com/Feliperodbar/autocase)

## 📸 Homolog

### Plataforma de Execução e Geração de Evidências para QA

O **Homolog** nasceu de um problema comum na rotina de testes:

> Executar uma etapa → tirar screenshot → abrir documento → inserir evidência → voltar para o sistema → continuar o teste.

A proposta é transformar esse processo em um fluxo mais rápido, organizado e rastreável.

O Homolog permite registrar passos de teste, capturar evidências e gerar documentação durante a execução dos cenários.

### Principais recursos

- 📝 Registro estruturado de passos
- 📸 Captura de screenshots
- 🔗 Associação entre passo e evidência
- 🧪 Execução organizada dos testes
- 📁 Gerenciamento de evidências
- 📄 Geração de relatórios
- 🌐 Exportação em HTML
- 📘 Exportação em DOCX
- 🖥️ Interface voltada à produtividade de QA
- 🌐 Evolução para extensão Chrome/Edge

### Visão do projeto

```text
REQUISITO
    ↓
CASO DE TESTE
    ↓
EXECUÇÃO
    ↓
PASSOS
    ↓
EVIDÊNCIAS
    ↓
RELATÓRIO
```

🔗 [Acessar repositório do Homolog](https://github.com/Feliperodbar/homolog1)

🌐 [Visualizar aplicação](https://homolog1.vercel.app/)
